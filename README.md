# Metronome

**An MEV-free exchange that clears every Monad block.**

Metronome is a fully onchain frequent batch auction exchange on [Monad](https://monad.xyz). All orders placed in a block are cleared together at one uniform price. The order of transactions inside the block doesn't matter, so front-running and sandwich attacks don't work. Monad's 300ms blocks keep it feeling real-time.

Built for the [Monad Metropolis hackathon](https://monad.xyz/developers/hackathons/metropolis) (Sep 1 – Oct 13, 2026).
