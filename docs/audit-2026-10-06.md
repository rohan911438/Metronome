## Findings

| # | Severity | Finding | Status |
|---|---|---|---|
| 1 | Medium | **CRE receiver accepted any workflow's reports.** The real forwarder checks DON signatures, but any CRE workflow can target any receiver. With the oracle guard on (the mainnet plan), a stranger's workflow could write a price that voids every batch (orders refunded, nothing fills) or loosens the guard. | **Fixed:** `MetronomeHeartbeat.setWorkflowOwner` checks the workflow owner in the report metadata (off by default for mock-forwarder simulations). The workflow's gas estimate now sends matching metadata. Test: `test_workflowOwnerCheck`. Set it on the mainnet receiver before turning the guard on. |
| 2 | Info | The testnet receiver points at CRE's **mock forwarder**, which doesn't verify signatures, so anyone can write a testnet price through it. | Accepted: the testnet oracle guard is off, so the price only steers the market maker's quotes. Never turn on the guard with a mock-forwarder receiver. |
| 3 | Low | `cancel` of a resting order first settles every earlier pending batch, so its gas grows with the backlog. | Accepted: anyone can call `settle(b)` in steps first; the keeper and CRE keep the backlog near zero. |
| 4 | Info | Fee-on-transfer or rebasing tokens would break escrow accounting. | Accepted: one market, WMON/AUSD, neither has transfer fees. |
| 5 | Info | Owner powers: `pause` stops only new orders (settle, claim and cancel still work); fees capped at 1% and never above what a taker escrowed; `setOracle` can void batches (refunds, never theft); `withdrawFees` limited to `feesAccrued`. No owner path reaches user escrow. | OK |
| 6 | Info | App keys: every key is derived from the passkey's PRF output and never stored; a pasted Perpl API key is AES-GCM encrypted with a passkey-derived key; the burner wallet only exists on the local chain or a dev fork; the Perpl proxy forwards only an allowlist of read paths. | OK |

## Operational risks before submission

- **Hosted app + indexer:** once the app is hosted, `/stats` needs `NEXT_PUBLIC_INDEXER_URL` pointing at a reachable indexer, otherwise it shows "not configured" (portfolio falls back to RPC).
- **Mainnet:** the deployer has no mainnet MON (~3 MON needed plus seed liquidity). Deploy the receiver with the new check.
- **Testnet gas:** running the MM and keeper burns MON fast; run them only for demos.
- **Sponsor rules:** Perpl, Mera, Nansen and Envio rules are still "TBC" in `tracks/`; check the dashboard before submitting.
